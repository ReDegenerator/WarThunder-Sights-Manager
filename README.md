# WarThunder Sights Manager
**!!!Эта программа сейчас находится в разработке и некоторый описанный функционал не работает или может дополниться!!!**

Это программа, которая создавалась для облегчения хранения большого количества прицелов. Из-за особенностей чтения игры при большом количестве прицелов(у меня 3600+ шт.) в меню выбора прицелов сильно падает fps. Программа нужна как связующее звено, т.е все прицелы будут храниться в программе, а в игру попадут только те, которые вы выберете в программе.

### Инструкция по установке:
1. Скачать последнюю версию программы по ссылке https://github.com/ReDegenerator/WarThunder-Sights-Manager/releases.
2. После установки положить в папку, которую вы должны создать для программы. После открытия программы в этой папке будут располагаться пользовательские файлы(прицелы, превью к прицелам, файлы групп, конфиг программы и кэш).
3. Теперь в программе можно выбрать путь к папке с прицелами игры. На данный момент (29.08.2026) это:
   
   C:\Users\[имя пользователя]\Documents\My Games\WarThunder\Saves\ [много цифр] \production\UserSights\all_tanks  (Обязательно all_tanks).

### Инструкция по установке прицелов:
1. Если вы выбрали папку прицелов игры и там уже есть установленные, то они автоматический перенесутся в программу(если их много программа может зависнуть на некоторое время).
2. Вы также можете перенести прицел(.blk файл) на программу, она скопирует его в свой репозиторий, не важно в каком количестве. С **.zip** тоже работает, сразу после установки прицела с WTLive(где всегда используются zip файлы) можно не распоковывая переносить их в программу, можно переносить сразу несколько .zip файлов.

# Структура программы

### Repository (репозиторий/список прицелов)
Это раздел для отображения абсолютно всех прицелов, которые находятся в репозитории программы.
<img width="1366" height="793" alt="image" src="https://github.com/user-attachments/assets/ab1e5b94-95bd-4366-b250-cb1759383403" />

### Структура раздела(Repository):

1. Слева стоит поле отображения прицелов(статус, название, наличие превью). Можно выделять много прицелов за раз комбинациями: Shift + ЛКМ (область выделения), ctrl + ЛКМ(точечное выделение). **Множественное выделение работает во всех списках прицелов в программе.**

2. Справа поле, отображающее превью прицелов. Он отображает превью одновременно всех выбранных прицелов и может прокручиваться, при наведении курсором на него вылезет окно с полным отображением прицела без обрезания до области рисунка. **Правое поле находиться во многих разделах и везде имеет такой же функционал.**<img width="1366" height="793" alt="image" src="https://github.com/user-attachments/assets/a930ba52-7ca9-4cb7-9bbc-96142a79df34" />

3. Кнопки Select all и Clear selected отвечают за выбор всех прицелов из списка и отмену любого выделения.

4. Кнопки "Delete selected" и "Activate selected" отвечают за удаления выбранного объекта и активацию соответственно(под активацией подразумевается копирования прицела в папку с игрой).

5. "Rebuild preview image" заново создает изображения для выбранных прицелов.

6. "Refresh sights list" заново ищет файлы в репозитории программы. Нужен только если вы в проводнике добавляли файлы.

7. Переключатель "Hide sights from group" отключает отображение прицелов, состоящих в группах.

### Groups(группы)

Тут располагаются созданные вами группы, думаю суть группирования прицелов писать не надо.
<img width="1366" height="793" alt="image" src="https://github.com/user-attachments/assets/e010ad27-c3c3-4f49-bdbc-4eb4c922fc5e" />

### Структура раздела(Groups):

1. Поле отображения списка групп. Отображает список групп с их функционалом:
    - **"+"** при нажатии раскрывает/скрывает содержимое группы.
    - **"Edit"** открывает область редактирования группы.
    - **"delete"** удаляет конкретную группу.

2. "Activate selected sights" и "Delete selected sights" активирует/удаляет выбранные прицелы.

3. Поисковик при вводе отображает только группы, содержащие подходящий прицел, внутри групп только подходящие по фильтру прицелы.

4. "[+]Create group" запускает диалоговое окно с вводом названия новой группы и последующим её созданием.

### Groups.Edit(Редактирование группы)

Это раздел для изменения содержания группы.
<img width="1366" height="793" alt="image" src="https://github.com/user-attachments/assets/7ba62aab-df61-48aa-aafc-fd136fb77e38" />

### Структура раздела(Groups.Edit):

1. Две области отображения прицелов, подписанные сверху как "Group" и "Repository". Отображают прицелы в группе и репозитории соответственно.

2. "up arrow" и "sown arrow". Это кнопки для переноса прицелов из репозитория в группу или исключения прицела из группы.

3. "Rename Group" кнопка для переименовывания группы.

4. Переключатель "Hide sights from other groups" отключает отображение прицелов, состоящих в других группах.

5. "Close" закрывает вкладку редактирования группы.

### Activated(Активированные)

Отображает исключительно активированные прицелы и нужен для удобного доступа только к активированным прицелам. Если прицел находится здесь, значит он скопирован в игру должен быть помечен своим статусом(отображается как зелёный круг).

<img width="1366" height="793" alt="image" src="https://github.com/user-attachments/assets/c3e2fd7d-f277-4afd-bbc6-5a64273c4e71" />

### Структура раздела(Activated):

1. Поле отображения списка активированных прицелов слева.

2. Кнопки "Deactivate selected" и "Delete" деактивирует(выключает)/удаляет выбранные прицелы.

3. Кнопки Select all и Clear selected отвечают за выбор всех прицелов из списка и отмену любого выделения.

### Settings

Раздел для настройки работы программы. Сейчас там только выбор пути к папке прицелов игры, но в дальнейшем функционал расширится.
